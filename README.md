# Sales Data Analysis
## Project Overview
This project focuses on analyzing restaurant sales data using Python to identify sales trends, understand product performance, and generate meaningful business insights.

The dataset contains sales transactions from restaurants across multiple locations, including London, Madrid, Lisbon, Berlin, and Paris, during November and December 2022.

## Objectives
- Analyze overall sales performance.
- Identify top-selling products and revenue contributors.
- Compare sales across different locations.
- Understand monthly sales trends.
- Generate insights to support business decisions.

## Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Google Colab

## Key Analysis
- Product-wise sales and revenue analysis.
- Location-wise revenue comparison.
- Monthly sales trend analysis.
- Payment method analysis.
- Data cleaning and exploratory data analysis (EDA).

## Key Findings
- Burgers generated the highest revenue among the products.
- Beverages and fries had high sales volumes.
- Lisbon recorded the highest revenue among the analyzed locations.
- December sales were higher than November sales.


## Conclusion
This project helped identify important sales patterns and business insights using Python-based data analysis and visualization.
